# ai77

Playground for visualizing medical records.

## Structure

- [`specs/`](specs/README.md): implementation-independent specification
  of what ai77 does. Read this first. Every implementation must conform to
  it. To change behavior, change the spec first, not only the code.
- [`AGENTS.md`](AGENTS.md): the rules for working in this repo, for humans
  and AI agents alike.

No implementation exists yet. When one is added, it gets its own top-level
directory (e.g. `web/`) with its own README covering setup and testing.
